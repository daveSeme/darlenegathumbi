# Darlene Gathumbi — Portfolio Website

A responsive editorial-style portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. No build step or npm dependencies are required.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, layout and animations
- `script.js` — mobile navigation, scroll progress and reveal effects
- `assets/` — add approved portrait and project images here

## Before publishing
- The hero uses a CSS illustration placeholder, not a real portrait. Replace it with Darlene's approved photo if available.
- The portfolio tiles are illustrative category graphics, not claims about completed client campaigns. Replace with verified work samples when available.
- Verify dates and descriptions with Darlene before publishing.
- Contact email, phone and WhatsApp links are wired.
- Google Fonts load online; fallback fonts are included.

## Deploy
Upload `index.html`, `style.css`, `script.js`, and `assets/` to GitHub Pages, Netlify or the public web root on cPanel.
